Backup & export

 

How to restore a backup or move to another drive

Your library lives in one folder on the server: the left side of the volumes: line in docker-compose.yml (./data unless you changed it).

Move to another drive

  1. Stop the app: docker compose down
  2. Copy the whole folder to the new location, e.g. cp -a ./data /path/on/nas/pantry-data
  3. In docker-compose.yml, change only the left side of the volume line: - /path/on/nas/pantry-data:/app/data
  4. Start it: docker compose up -d, and check your recipes are there before deleting the old folder.

Restore a full backup

  1. Stop the app: docker compose down
  2. Unzip the backup into the data folder so recipes.db and uploads/ are directly inside it: unzip -o open-the-pantry-backup-*.zip -d ./data
  3. Start it: docker compose up -d

Restoring replaces everything currently in the app. Always stop the app first: replacing the database while it runs can corrupt it.

The backup doesn't include the email encryption key. If you use email ingest, copy encryption.key from the old folder too, or set up encryption again and re-enter the password.
